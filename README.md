# PDF 여백 자르기

카테고리마다 “어느 페이지를 위·아래·왼쪽·오른쪽 몇 cm 자를지” 규칙을 정해 두고, PDF를 넣으면 그 규칙대로 잘라 주는 휴대폰용 웹앱입니다.

## 개인정보와 보안

- PDF와 카테고리 설정은 **기기 안에서만** 처리·저장됩니다. 이 앱에는 파일을 받는 서버가 없습니다(정적 파일만 있음).
- 앱 페이지에 콘텐츠 보안 정책(CSP)을 걸어, 앱이 **다른 인터넷 주소와 통신하지 못하게** 막았습니다. 외부 글꼴·외부 스크립트도 쓰지 않습니다.
- 한 번 열면 앱 파일이 기기에 보관되어 **인터넷 없이도(비행기 모드) 작동**합니다.
- 자르기는 PDF의 보이는 영역(CropBox·MediaBox)을 줄이는 방식입니다. 잘린 부분의 내용은 파일 안에 남으므로, 개인정보를 지우는 용도에는 PDF 편집기의 가리기(redaction)를 쓰세요.

## 설치

- **iPhone (Safari)**: 주소를 열고 공유 버튼 □↑ → “홈 화면에 추가”.
- **Android (Chrome·삼성 인터넷)**: 주소를 열고 “앱 설치” 또는 메뉴 → “홈 화면에 추가”.
- 처음 한 번은 앱 파일(약 7 MB)을 받으므로 와이파이에서 여는 것을 권합니다.

## 포함한 오픈소스

- [pdf-lib](https://github.com/Hopding/pdf-lib) 1.17.1 — MIT
- [PDF.js](https://github.com/mozilla/pdf.js) 6.2.108 (pdfjs-dist legacy build) — Apache-2.0
- PDF.js에 딸린 CMap·표준 글꼴·이미지 해독기 — 각 라이선스는 `vendor/LICENSES/`에 있습니다.

CMap·글꼴·해독기 파일은 원본 바이너리를 base64로 담은 `.json`으로 넣었습니다(내용은 같음).
